PDF text extractor

Many textbook PDFs store Urdu with custom fonts: extraction can show random Latin/CJK symbols (not fixable by choosing Jameel Noori). Enable Simple text to drop those lines so English exercises stay readable. Text is reassembled by position (lines top-to-bottom, words left-to-right or right-to-left for Arabic script lines). Mixed layout shows Latin text left-to-right and Arabic-script text right-to-left (same characters as extraction — use Copy for the exact plain text). Turn it off for a single-direction editor.
