Instructions for Bulk Admission

  • Select input method: Manual Entry or CSV Upload.
  • Select the Class and Section before entering student data.
  • For Manual: set number of students and fill in the forms below. Only non-empty rows are submitted.
  • For CSV: download the sample file, fill in student details, then upload the completed file.
  • Each student must have a unique Student Code — duplicates will be skipped.
  • Click "Import All Student Data" to process and save records.
  • After successful import you will receive a confirmation message with the count of added students.
