Your folder: C:\Users\laptop World\Downloads\sallybus
==============================================

1) Put in that folder (same structure):
     sallybus generator.html
     data\sallybus-bundle.json          ← ONE file the HTML loads (curriculum + class keybooks)
     data\keybooks\                     ← PDFs copied here by the build script (relative links)

2) Build the bundle on your PC (downloads/copies PDFs → writes JSON + keybooks):

   Copy the repo folder "tools" next to your project OR run from repo root.

   - Copy tools\build-bundle-config.example.json to tools\build-bundle-config.json
   - Edit paths and "class" names so they match your curriculum class names
     (must match exactly, e.g. "Class 8" if that is in syllabus-by-class.json).

   Then:
     python tools\build_sallybus_bundle.py tools\build-bundle-config.json

   Output: data\sallybus-bundle.json and files under data\keybooks\

3) Open the HTML with a local server (so fetch works), from the folder that contains the HTML:
     npx --yes serve .

4) Optional: merged PDF from multiple sources — see merge_skillup_pdfs.py
