# Hassan — Personal Portfolio

A modern, responsive portfolio website built with pure HTML, CSS, and JavaScript — no frameworks required.

## Features

- **Hero section** with animated typewriter effect and parallax blobs
- **About section** with animated counter stats
- **Skills section** organised by category (Front End, Back End, Tools)
- **Projects section** showcasing featured work with live/GitHub links
- **Contact section** with a working form UI
- Fully **responsive** (mobile, tablet, desktop)
- Smooth **scroll animations** and hover interactions
- Dark theme with a purple/indigo accent palette

## Structure

```
├── index.html   # Main markup
├── style.css    # All styles & animations
└── script.js    # Interactions (typewriter, counters, AOS, form)
```

## Customisation

Edit `index.html` to update:
- Your name, bio, and profile info in the **About** section
- Project titles, descriptions, and links in the **Projects** section
- Email address and social links throughout
- Skill badges to match your actual stack
